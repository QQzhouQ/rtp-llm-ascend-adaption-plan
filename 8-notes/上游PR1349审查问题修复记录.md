## 一、P0 问题（2 个）

### P0-1：ROCm 下 graphCaptureBegin 不再调用 capture_begin，既有平台的图捕获被静默破坏

- **位置**：`rtp_llm/cpp/cuda_graph/cuda_graph_device_shims.cc:212`（附带 `shims.h:49-53` GraphPoolHandle）
- **问题**：我们 Ascend 适配时把 ROCm 分支的 `graph.capture_begin()` 一并改成了 `(void)graph` 空操作——ROCm 图捕获被静默破坏。
- **修复**：
  1. `shims.cc` 恢复三分支（对齐上游）：
     ```cpp
     void graphCaptureBegin(at::cuda::CUDAGraph& graph, GraphPoolHandle pool) {
     #if USING_CUDA
         graph.capture_begin(pool);
     #elif USING_ROCM
         // HIP graphs do not use mempools; GraphPoolHandle is an empty struct here.
         (void)pool;
         graph.capture_begin();
     #else
         (void)pool;
         (void)graph;
     #endif
     }
     ```
  2. `shims.h` 声明恢复上游单声明 `void graphCaptureBegin(at::cuda::CUDAGraph&, GraphPoolHandle)`（我们之前为 Ascend 改成了 `void*` 重载，属第三种命名扩散）。Ascend 无法 include `ATen/cuda/CUDAGraph.h`（级联拉 `cuda_runtime_api.h`），用**前置声明**解决——引用参数不需要完整类型：
     ```cpp
     namespace at { namespace cuda {
     // Forward declaration suffices for the reference parameter below; Ascend
     // builds never include ATen/cuda/CUDAGraph.h (it pulls cuda_runtime_api.h).
     struct CUDAGraph;
     } }
     ```
- **未做**：MI308X ROCm 冒烟 + ROCm 图捕获测试（无 ROCm 机器；建议 CI 或有环境者补）。

### P0-2：Ascend pip lock 文件未提交 + 三种命名不一致 + 顶层无条件 load 阻塞所有平台

- **位置**：`deps/pip.bzl:89`、`WORKSPACE:80-81`、`arch_config/arch_select.bzl:8`、根级悬空软链
- **问题**：`pip_ascend_torch` 引用 `requirements_lock_ascend_x86.txt` 但未提交；根级还有一个 `requirements_lock_ascend.txt` 悬空软链（第三种名字）；顶层无条件 load 导致 cuda/rocm/arm/cpu 全部配置在 loading 阶段失败。
- **修复**：
  1. 删除根级悬空软链 `requirements_lock_ascend.txt`
  2. `deps/requirements_lock_ascend_x86.txt` **加入暂存待提交**（此前按用户要求未提交，上游 P0 要求必须提交，待最终确认）
  3. 命名统一为 `requirements_ascend_x86.txt` / `requirements_lock_ascend_x86.txt`（pip.bzl/BUILD/WORKSPACE 三处一致，前轮已完成，本轮复核）
  4. `deps/BUILD` 显式导出：
     ```python
     exports_files([
         "requirements_base.txt",
         "requirements_ascend_x86.txt",
         "requirements_lock_ascend_x86.txt",
     ```

  5. `deps/pip.bzl:90` TAB 缩进修正为空格
